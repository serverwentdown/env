
# Local Environment

## Nix

This specific environment uses Nix. On macOS, some applications are available
in `~/Applications/Home Manager Apps/`, including Firefox.

## Web Browser

Always use Firefox instead of Chrome/Chromium, including when using Playwright.

## Creating PRs

After creating PRs, enable auto-merge (unless it is a breaking change) and
automatically open them in a web browser without prompting.

To the bottom of the PR description, add a note on what AI model and settings
were used to create the PR.

When updating any PR descriptions, retain the PR description generated by
Cursor.
